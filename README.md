# A City Is Sometimes Kind of a Tree

Code and manuscript for a study of street network treeness in 9,923 urban
areas worldwide. Each network is compared with its length-weighted minimum
spanning tree (or forest for disconnected networks). Link redundancy, theta,
is the share of edges beyond the spanning tree. Length redundancy, lambda,
is the share of total street length beyond it.

Street network models and urban indicators come from
[street-network-models](https://github.com/gboeing/street-network-models). GDP data come from the fixed v1.1 GHSL data set, [GHSL Urban Centre Database R2024A V1.1](https://doi.org/10.2905/1a338be6-7eaf-480c-9664-3a8ade88cbcd), by dividing total 2020 GDP by 2020 resident population: both totals cover the same fixed 2025 urban centre boundary.
